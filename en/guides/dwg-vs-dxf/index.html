DWG vs DXF: the difference

Both are AutoCAD drawings, but they serve different jobs. What's the same, what differs, and which to pick when the drawing leaves your program or goes to an iPad.

Updated 2026-09-10 · About 3 min read

One line

DWG is AutoCAD's binary native format; DXF (Drawing Exchange Format) is the same content written out as text for exchange. Inside the company, DWG. Handing off to another program or device, DXF.

Comparison

ItemDWGDXF
StructureBinary, changes by versionText (ASCII), group code / value pairs
File sizeSmallSame drawing 4–6× larger
Programs that open itAutoCAD and programs with a DWG engineAlmost every CAD, GIS and CAM
Layers, colors, weights, linetypesKeptKept
Blocks, hatches, dimensionsKeptKept (dimension styles vary by program)
External references (Xref)Linked by pathLinked by path (not embedded)
When damagedHard to recover without toolsText, so partial recovery is possible
On iPad without a connectionNeeds conversion (app-dependent)Fluxketch reads it directly, offline

Why DXF is bigger

DXF writes every value as text. One coordinate is 8 bytes in binary but as text it becomes two lines — a group code (10) and a value (123456.789012) — as long as its digits. The same drawing grows four to six times, yet the entity count is identical. Whether an iPad app can open it should depend on entity count and device memory, not file size.

When DWG, when DXF

  • Between AutoCAD users: DWG. Small and fast.
  • To another CAD (BricsCAD, ZWCAD, DraftSight…): both open, DXF is the safe bet.
  • To iPad or mobile: save as DXF (2018 ASCII) and any app opens it offline.
  • To laser, CNC or GIS: DXF. Most accept only DXF.
  • Archiving: keep both, and any future program will open one of them.

Check before converting

  1. Unit. Many DXFs have an empty $INSUNITS header. The opening side must ask.
  2. Version. For older programs save as 2000 or 2004 DXF. Newer elements (multileaders and so on) don't exist in old versions.
  3. External references. Xrefs aren't embedded. Bind (insert) them before handing off.
  4. Fonts. SHX and TTF fonts aren't in the file. If the opening side lacks them, a substitute is shown.

The iPad choice

Save as DXF before leaving for site and it opens with no connection. If all you have is DWG you need an app that opens it directly, and what matters is whether layers and linetypes survive conversion and whether skipped elements are reported. Details in How to open DWG files on iPad.
